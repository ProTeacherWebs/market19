# Компоненты Velin

Тёмная тема на весь сайт. Токены из PRD:

| Токен | Значение |
| --- | --- |
| `--bg` | `#08090B` |
| `--surface` | `#101216` |
| `--surface-raised` | `#191C21` |
| `--border` | `#34383E` |
| `--text` | `#F2F2F0` |
| `--muted` | `#A9ADB4` |
| `--accent` | `#C9CDD2` |
| `--success` | `#7DB49A` |
| `--danger` | `#D68181` |

Промо и герой: Cormorant Garamond. UI, цены, формы, логотип: Geist. Поверхности 16 px, контролы 12 px.

Кнопки, поля, select, badge, dialog, toast и skeleton описаны классами в `src/app/globals.css`. Карточка товара ведёт на `/p/[slug]`. На главной хиты - `FeaturedStrip` (крупный lead + список), не равная сетка карточек. Мобильное меню закрывается по Escape. Диалог демо-каталога закрывается по Escape, кнопке и клику по фону.

Движение: появление заголовка героя и featured 520-600 ms, hover 180 ms. При `prefers-reduced-motion` сдвиг и масштаб отключаются. Фото категорий взяты с Unsplash и общие для моделей одной группы.
